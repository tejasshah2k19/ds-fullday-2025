Array : 
            collection of same type of data with continuous memory allocation.

                1) one dimension   [] 
                2) two dimension   [][] 
                3) multi dimension [][][] , [][][][] , +++

    int arr[5];   ==>  arr 5  copy 
   
    how to access  : using  index 
    index always starts with 0 and ends with SIZE-1 

    arr[0] = 2
    arr[1] = 7
